# 📡 Laboratório de Inovação II: Radar de Tecnologias

Site da disciplina **Laboratório de Inovação II** (ADS, 2º semestre, quintas à noite, Taguatinga) da
Faculdade de Tecnologia e Inovação Senac DF, com a Profa. Maristela (Stela).

**No ar:** https://maristelaoliveira.github.io/lab-inovacao-2/

## O projeto do semestre

Em grupos, a turma investiga tecnologias atuais e em projeção (IA generativa, nuvem, IoT, cibersegurança,
blockchain, low-code, realidade estendida), apresenta seminários, conduz workshops, participa de mesas de
debate e publica tudo num portfólio no GitHub Pages: o **Radar de Tecnologias**.

| Pasta | O que é |
|---|---|
| [`index.html`](index.html) | Página da disciplina: ementa, objetivos, unidades, aulas, avaliação e bibliografia |
| [`aulas/`](aulas/) | Uma página por aula, com conceitos, estudo de caso, atividade e checklist |
| `assets/` | Visual comum aos sites da Stela (placa de circuito, tema claro e escuro, chuva de 0 e 1) |

## Tecnologia

HTML, CSS e JavaScript puros, sem framework e sem etapa de build. Acessível: tema claro e escuro, aumento
de texto e botão para pausar as animações em todas as páginas.

Feito com ♥ e sucata eletrônica.
