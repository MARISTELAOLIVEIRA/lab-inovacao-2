O portfólio ganha endereço

Repositório, primeiro commit e o site do grupo no ar com o GitHub Pages.

Objetivo do dia

Criar o repositório e publicar a primeira versão do portfólio do grupo.

Antes da aula

Criar uma conta no GitHub, se ainda não tiver.

Como conta ponto

Link do portfólio no Teams.

C1–C3 · conceitos

Do repositório ao site

C1

O que vai no portfólio

Apresentação do grupo, ficha técnica da tecnologia, aplicações, referências e o registro dos workshops e dos debates.

Ele cresce durante o semestre: hoje nasce a primeira versão.

C2

GitHub em três palavras

Repositório: a pasta do projeto na nuvem. Commit: uma foto do projeto num momento, com uma mensagem. GitHub Pages: transforma o repositório num site com endereço próprio.

C3

Uma página simples

O modelo da professora já vem pronto. O <h1> é o título, o <p> é o parágrafo e o <a> é o link.

1<h1>Radar: Internet das Coisas</h1>2<p>Grupo: Ana, Bia, Caio e Davi</p>34<h2>O que é</h2>5<p>Objetos que medem e conversam6   pela internet.</p>78<a href="ficha.html">Ficha técnica</a>
EC1 · estudo de caso

O portfólio que ninguém achou

O grupo fictício Nuvem Rosa fez um portfólio caprichado, mas deixou o repositório privado, com o nome teste123 e sem README. Na hora da apresentação, ninguém conseguia abrir o link.

O grupo vizinho publicou uma página simples, com nome claro, README explicando o projeto e o link no Teams desde o primeiro dia.

Para discutir em grupo

  1. O que faz um portfólio ser encontrado e entendido?
  2. Que nome vocês vão dar ao repositório?
  3. O que precisa estar no README desde hoje?

Caso fictício, criado para a aula.
